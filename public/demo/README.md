# 시연 사진

기억 내용은 모두 창작이며 사진에 등장하는 인물·촬영자 경험을 재현하지 않는다. 예시 날짜는 실제 사진 촬영일이 아니다. 상세 화면에도 출처와 라이선스를 표시한다.

- `taehwagang.png`: 기존 유랑 독립 시안의 가상 시연 이미지. 기존 파일을 수정 없이 재사용.
- `daewangam-day.jpg`: Shinfull, [Daewangam Park.jpg](https://commons.wikimedia.org/wiki/File:Daewangam_Park.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), 원본 다운로드. UI에서 크기·잘림 조정.
- `daewangam-night.jpg`: Shinfull, [Daewangam Park02.jpg](https://commons.wikimedia.org/wiki/File:Daewangam_Park02.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), 원본 다운로드. UI에서 크기·잘림 조정.

Wikimedia 이미지의 저작권은 위 저작자에게 있으며 해당 이미지와 파생물에는 표시된 라이선스를 적용한다. 앱 소스의 라이선스와는 별개다.
