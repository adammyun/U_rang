# 기억 댓글 검증

- 거리뷰 위 앱 HTML 패널과 거리뷰 실패→단일 기억 상세 fallback을 같은 댓글 컴포넌트로 구현했다.
- 댓글 관련 16건 + 이전 저장소 보존 4건: Chromium/WebKit, 1440×900·390×844에서 **20/20 통과**.
- 장소 포스트잇·개별 상세 이동·마이페이지 기존 회귀 검사 **24/24 통과**. 댓글을 추가하는 과정의 첫 검사에서 상세와 거리뷰 sibling key 충돌을 발견하고 `panorama:` namespace로 구분한 후 해당 흐름을 다시 통과했다.
- 로컬 D1 migration 성공. 서버 API 검사: 인증, 1–1000자/식별자 위조 차단, same-origin, 익명 DTO, 30개 cursor 페이지, private/unlisted 제외, 본인만 삭제, 기억 삭제 cascade 통과.
- v2/v4→v5의 기존 글·사진·수정된 예시·반응 보존과 브라우저 기억 삭제 시 댓글/반응 정리를 확인했다.
- 많은 댓글을 가진 내부 영역의 실제 overflow/스크롤과 다음 페이지를 확인했다. 모바일 실제 소프트 키보드와 손가락 제스처는 장치에서 추가 확인할 수 있다.

`comments-overlay-*.png`는 SDK 테스트 대역으로 HTML 패널/입력/스크롤을 검증한 캡처다. 회색 배경은 실제 거리뷰 촬영 영상이 아니다. `comments-fallback-*.png`는 거리뷰를 사용할 수 없을 때의 실제 앱 상세 화면이다.

실서비스 계정에 로그인한 후의 댓글 작성은 로컬 모의 인증 검사와 구분해 보고한다. NAVER 실제 영상 위 공개 열람 검증은 배포 후 수행한다.
