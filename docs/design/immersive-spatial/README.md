# Apple Spatial Memory · 독립 미리보기

기존 서비스 메인 화면을 교체하지 않는 시각적 프로토타입이다. 실제 앱의 API·인증·기억 작성·개인정보 처리와 연결하지 않았다.

## 실행

저장소 루트에서 `pnpm preview:immersive`를 실행한 뒤 `http://127.0.0.1:4330/`을 연다. 터미널에서 실행 중인 미리보기 서버를 종료하면 이 주소도 열리지 않는다. 시각 검증과 스크린샷은 `pnpm test:immersive`로 다시 생성한다.

## 탐색 흐름

1. 지도를 전체 화면에서 탐색한다. 마커가 위치한 장소를 선택한다.
2. 작은 장소 미리보기에서 이야기 한 편을 선택한다.
3. 데스크톱에서는 사진 중심의 편집형 패널이 지도 위에 펼쳐지고, 모바일에서는 상세 바텀 시트가 확장된다.
4. 전체 목록이 필요할 때만 하단의 **탐색**을 연다.

검색의 장소 제안, 지도 확대·축소, 현재 위치, 패널 열기·닫기는 시안 안에서 동작한다. **기억 남기기**와 **내 기억**은 실제 서비스 기능이 이 시안에 연결되지 않았음을 알린다.

첫 방문에는 대표 마커에 짧은 시작 안내가 보이고, 장소를 선택하면 사라진다. 검색에는 결과 수와 결과 없음 상태가 있다. 사진이 없는 가상 기억을 선택하면 해당 장소의 글과 사진 없음 상태를 표시한다.

지도는 실제 서비스와 같은 MapLibre GL JS와 OpenFreeMap Positron 스타일을 사용한다. 지도 렌더링을 사용할 수 없는 브라우저에는 시안 전용 배경이 남는다. 지도 데이터는 OpenStreetMap 기여자를 표시한다. 상세 이미지와 텍스트는 실존 인물의 기록이 아닌 가상의 시안 자료다.
