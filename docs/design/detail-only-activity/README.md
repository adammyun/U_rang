# 장소 미리보기의 반응 영역 제거

사용자 요청에 따라 여러 포스트잇을 펼친 장소 화면에서 좋아요·북마크·조회수 영역을 제거했다. `PlaceNoteBoard`에서 반응 컴포넌트와 인증 prop, 전용 CSS를 제거했다. 개별 상세의 `MemoryActivityBar`, 저장 데이터, 마이페이지·지도 필터와 권한 정책은 유지한다. 조회 기록은 개별 상세를 열 때만 남긴다.

검증: `pnpm check` 통과(단위 11개, lint·타입 검사·양쪽 빌드). 데스크톱/모바일 Chromium·WebKit에서 다섯 포스트잇, 반응 영역 부재, 개별 상세의 반응 설정·취소, 로그인 경계와 마이페이지를 확인했다. 미리보기를 열기만 해서는 activity 요청이 발생하지 않는 것도 검사한다.

첫 12개 실행은 11개 통과·모바일 Chromium 1개 시간 제한 중단이었다. 같은 코드로 중단된 검사를 단독 재실행해 통과했다(6.5초). 검사 기준과 제한 시간은 변경하지 않았다. 운영 계정 로그인 이후 동작은 이번 범위에서 직접 재검사하지 않았다.
