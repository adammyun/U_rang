# 기억 본문과 개발 도구 확인

2026-10-25

예시 24개(공개 23·비공개 1)를 장소 설명 대신 그날을 되짚는 일기로 바꿨다. 기억 본문과 상세의 시연 안내 문구는 제거하고 외부 사진의 저작자·라이선스는 보존했다. 이야기는 창작이며 실존 인물의 경험을 사용하지 않는다.

공통 문장은 `src/features/memories/demo-journals.ts`에서 관리한다. D1에서는 예약된 ID·작성자·최초 생성 시각이 일치하고 수정 이력이 없는 예시만 갱신한다. Pages IndexedDB v3도 같은 원칙을 적용해 실제 사용자 글·사진과 수정한 예시를 보존한다. 스키마와 권한 정책은 변경하지 않았다.

개발 도구는 공개 지도 하단 문구를 2초 안에 5번 탭/클릭하면 열린다. 공통 graphite/coral·고딕·종이 표면과 지도 복귀 링크를 유지하고 Safari의 텍스트 선택을 막아 반복 탭을 보완했다.

검증: `pnpm check` 통과(단위 11개 포함). Chromium·WebKit 데스크톱/모바일 브라우저 검사 28/28 통과. 격리한 로컬 D1에서 이전 본문 갱신과 사용자가 수정한 비공개 본문 보존을 확인했다. 생산 환경의 실제 계정 작성·수정·삭제는 이번 범위에서 재검사하지 않았다.
