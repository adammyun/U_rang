# 여운 디자인 DNA

작성일: 2026-10-12  
적용 범위: 메인 공개 기억 지도

## 정체성

여운의 디자인은 **Quiet Archive의 따뜻한 기록 감성**과 **Civic Atlas의 명료한 조작 체계**를 결합한다. 지도는 차분한 배경으로 남고, 장소에 쌓인 기억이 종이 기록처럼 읽혀야 한다. 감성은 제목, 여백, 이야기 카드에서 드러내며 검색·필터·확대·현재 위치 같은 도구는 처음 보는 사람도 바로 이해할 수 있게 같은 크기와 상태 규칙을 사용한다.

## 디자인 원칙

1. 이야기가 지도 도구보다 먼저 읽히되, 지도 조작은 언제나 찾기 쉬워야 한다.
2. 핵심 행동인 `기억 남기기`만 따뜻한 주홍색을 사용한다.
3. 감정 색상은 마커와 작은 상태점에 제한한다.
4. 공개 범위, 익명성, 위치 정밀도 등 개인정보 선택은 장식보다 문장과 상태 차이로 분명하게 전달한다.
5. 모바일은 지도와 기억 목록을 동시에 이해할 수 있는 하단 시트 구조를 유지한다.
6. 모든 주요 조작 영역은 최소 44×44px을 확보한다.

## 컬러 토큰

| 역할 | 값 | 용도 |
| --- | --- | --- |
| Forest | `#315848` | 브랜드, 선택, 보조 행동 |
| Forest deep | `#223D33` | 제목과 강한 본문 |
| Persimmon | `#C55743` | 핵심 CTA |
| Rice | `#F4F0E7` | 전체 캔버스 |
| Paper | `#FFFCF6` | 카드와 패널 |
| Mist | `#EDF0E8` | 선택 배경, 약한 구획 |
| Ink | `#24322B` | 기본 텍스트 |
| Muted | `#6F7971` | 설명과 메타데이터 |
| Line | `#DCDDD4` | 경계선 |

텍스트 대비는 WCAG AA를 기준으로 확인한다. 반투명 지도 도구는 흐림 효과와 불투명한 경계를 함께 사용해 지도 위에서도 읽히게 한다.

## 타이포그래피

- 이야기 제목과 브랜드: `Noto Serif KR`, `Batang`, `Georgia` 계열
- 본문과 인터페이스: `Arial`, `Apple SD Gothic Neo`, `Noto Sans KR`, 시스템 sans-serif
- 화면 제목: 30–34px, line-height 1.42
- 카드 제목: 17–19px, line-height 1.5
- 본문: 14px 이상, line-height 1.7 이상
- 보조 정보: 12px 이상
- 영문 eyebrow는 대문자, 0.16–0.2em 자간을 사용한다.

외부 폰트 네트워크 의존성을 추가하지 않고 현재 시스템 폰트 폴백을 유지한다.

## 형태와 간격

- 간격 단위: 4, 8, 12, 16, 20, 24, 32px
- 이야기 카드 radius: 18px
- 지도 도구 radius: 14px 또는 pill
- 모바일 하단 시트 radius: 28px 28px 0 0
- 그림자는 패널을 지도와 분리할 때만 사용한다.
- 데스크톱은 424px 이야기 rail과 유연한 지도 영역으로 구성한다.

## 인터랙션

- hover/focus/선택 전환: 160–220ms
- 패널과 카드 진입: 240–300ms
- 카드 hover 이동은 최대 3px
- `prefers-reduced-motion`에서는 이동과 반복 애니메이션을 제거한다.
- 키보드 focus는 Forest 계열 2px outline으로 표시한다.

## 메인 화면 구성

### 데스크톱

- 상단: 브랜드와 최소한의 주 메뉴
- 왼쪽: 제품 문장, 현재 지도 주변의 기억 수, 스크롤 가능한 카드 목록
- 오른쪽: 지도, 장소 검색, 지도 조정, 확대·축소, 현재 위치, 기억 남기기

### 모바일

- 상단: 브랜드와 지도/로그인 메뉴
- 중앙: 지도와 겹치지 않도록 정렬된 검색·조정·확대 도구
- 하단: 손잡이가 있는 기억 목록 시트와 가로 스냅 카드
- CTA는 시트 바로 위 왼쪽에 고정해 한 손 조작을 돕는다.
