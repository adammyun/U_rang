# 유랑 — Memory Atlas

## 디자인 철학

지도를 사진과 글 조각이 놓인 살아 있는 기록 공간으로 사용합니다. 지리적 위치는 정확하게 연결하고, 사람의 기억은 종이와 사진의 물성으로 드러냅니다. La Gata Perduda의 전체 지도·비대칭 장면·콘텐츠에 반응하는 색조를 재해석했습니다. 해당 사이트의 자산·코드·글꼴을 복제하지 않습니다.

화면의 조작은 가장자리로 물러나고 선택한 이야기가 전경을 차지합니다. 자유로운 모습에도 읽기 순서, 안정적인 지리적 앵커, 명확한 돌아가기 경로가 있어야 합니다. 작성과 개인정보 정책을 장식 효과에 맞춰 바꾸지 않습니다.

## 타이포그래피

- 서비스 이름은 유랑입니다. 제목·본문·메타 정보는 로컬 Noto Sans KR 400/600 → 시스템 sans-serif 폴백을 사용합니다. 명조·세리프는 사용하지 않습니다. 제목 위 장식용 overline은 사용하지 않습니다. 날짜·감정 등 실제 정보는 제목 아래에 두고, 메인 제목은 “기억을 거닐다 / 유랑”으로 두 줄에 표시하고 유랑에 산호색을 적용합니다.
- 본문과 날짜에도 같은 고딕체를 사용하고 굵기·크기·간격으로 위계를 표현합니다.
- 메인 제목은 넓은 화면 38–58px, 모바일 30–36px로 조절합니다. 장문 상세 제목은 word-break: keep-all과 긴 문자열의 안전한 줄바꿈을 함께 사용합니다.
- 기록 본문은 13–14px, 약 2배 줄 간격을 사용합니다. 작은 마커는 읽기 화면의 대체물이 아니므로 제목 일부만 보여 주고 전체는 상세에서 읽게 합니다.
- 외부 글꼴 서비스나 유료 글꼴을 필수 실행 조건으로 추가하지 않습니다.

## 공간·레이아웃

데스크톱은 전체 지도, 좌상단의 작은 브랜드, 우상단 검색, 좌하단 감정 칩과 조정, 하단 가장자리의 내비게이션을 둡니다. 기억 남기기 CTA는 하단 왼쪽의 산호색 버튼입니다. 중앙 고정 pill dock과 영구 대형 공개 기억 목록을 기본 화면에 두지 않습니다.

사진은 허용된 실제 media를 사용하고, 사진 없는 기억은 날짜·제목·감정이 있는 글 조각으로 나타냅니다. 지도 앵커와 마커 내부의 기울임을 분리합니다. 기울기는 ID로 결정하고 지도 이동이나 재렌더마다 다시 무작위로 만들지 않습니다.

데스크톱 상세는 지도 위 색조와 사진 묶음, 검은 제목 띠와 별도의 본문 종이를 가진 고딕 읽기 장면으로 확장됩니다. 내 기억 상세도 같은 읽기 컴포넌트를 사용하며 owner 수정·삭제·공개 범위 표기를 유지합니다. 장문은 장면 내부에서 스크롤하며 닫기·뒤로가기는 고정합니다. 사진 0/1/5장의 구조를 다룹니다. 지도 인스턴스는 장면 전환 중에도 유지합니다.

## 버튼·표면

둥근 유리 패널 대신 작은 radius, 얕은 선, 종이의 짧은 그림자와 테이프 표현을 사용합니다. 모든 표면을 기울이거나 글 전체를 흔들지 않습니다. 입력·검증·파괴적 행동의 의미는 기존 컴포넌트를 유지합니다.

주요 버튼은 산호색의 불투명 면, 지도 보조 조작은 어두운 면과 읽을 수 있는 테두리, 글 읽기 도구는 짙은 표면 위 구분 가능한 면으로 표현합니다. Hover, active, disabled, selected, focus-visible을 빠뜨리지 않습니다.

## 모션

- 마커의 내부 사진·종이는 220ms 전환으로 조금 들리고 정렬됩니다. 좌표를 소유한 외부 버튼의 transform을 hover가 덮어쓰지 않습니다.
- 장소 종이는 약 320ms, 상세 종이는 약 380ms, 사진 진입은 약 500ms, 닫기는 170ms로 구성했습니다.
- 감정 색조는 opacity 전환으로 연결하고 매 프레임 지도 전체에 무거운 blur를 계산하지 않습니다.
- 커서 링은 fine pointer에서만 보조로 표시하며 기본 커서를 없애지 않습니다. requestAnimationFrame으로 화면 갱신을 제한합니다.
- reduced-motion에서는 진입·이동 효과와 커서 링을 끄고 닫기를 즉시 실행합니다.
- 지도 휠·드래그에 별도의 smooth-scroll 엔진을 추가하지 않습니다.

## 반응형·접근성

390×844 모바일에서는 상단 브랜드·검색, 하단 왼쪽 CTA와 짧은 내비게이션, 터치 가능한 감정 칩을 제공합니다. 상세는 전체 데스크톱을 축소하지 않고 위쪽 도구와 내부 스크롤을 가진 하단 읽기 장면으로 전환합니다. 장면의 장식용 중복 사진은 모바일에서 숨기며 실제 모든 사진은 본문에서 읽을 수 있습니다.

마커와 주요 조작은 최소 44px 목표로 구성합니다. 버튼의 이름·선택 상태, 장면의 dialog 의미, 키보드 focus, Escape, Tab 순환, reduced-motion을 유지합니다. 지도 출처 표기는 분위기 효과보다 위에서 읽히도록 독립 계층을 사용합니다.

## 재사용 가능한 표현 컴포넌트

- `MemoryStamp`: 허용된 기억과 좌표를 받아 사진·글 조각을 표현합니다. 데이터 fetch·권한 결정을 하지 않습니다.
- `AtlasAtmosphere`: 질감·감정 색조·포인터 보조 효과만 담당합니다.
- `SpatialPlacePreview`: 실제 장소 그룹의 맥락과 기억 미리보기를 표현합니다.
- `SpatialMemoryDetail`: 실제 기록의 읽기 장면, 닫기·뒤로가기·같은 장소 이전/다음을 표현합니다.

범용 프로젝트에서는 위 역할과 공간 위계를 재사용하고, 여운의 타입·좌표·감정·인증 구현까지 함께 복사하지 않습니다.

## 유랑 전용 기능 경계

- 울산 중심·현재 위치 정책, MapLibre lifecycle, 크기 보정, ResizeObserver, raster compatibility layer, 단일 marker overlay와 출처 표기를 보존합니다.
- 사진/글 스탬프의 화면상 grouping 반경은 72px입니다. 이는 종이 마커의 충돌을 줄이는 표현 규칙이며 서버의 장소 반경 100m는 바꾸지 않습니다.
- 화면상 묶음이 100m 이상 떨어진 장소들을 포함하면 먼저 확대해 분리합니다. 위치 선택 중에는 기존 위치 선택 동작을 우선합니다.
- 공개 viewport query, abort 처리, public/private/unlisted, anonymous, approximate 응답 경계를 그대로 사용합니다.
- owner 관리·사진 업로드·검증·삭제 확인·튜토리얼·개발 보조 진입점·NAVER 거리뷰 callback은 기존 기능을 재사용합니다.
- Worker/App Router와 Pages의 두 entry에서 마지막 CSS를 공유합니다. Pages의 데이터·로그인은 브라우저 로컬이며 사용자 간 서버 공유가 아닙니다.
- 이미지가 없는 공개 seed에 임의의 사용자 사진을 삽입하지 않습니다.

## 검증

데스크톱 1440×900 및 모바일 390×844, 낮은 화면 1280×720 및 390×667의 최종 단일 워커 Playwright 40개 테스트가 통과했습니다. 튜토리얼 열 단계·사진 5장·긴 본문·비공개 미노출·현재 위치·장소 내 다음 기억·reduced-motion·키보드 복귀에 더해 라인 지도 좌표 일치·데이터 실패 fallback·기억 범위 전환·조정의 독립 스크롤과 버튼 겹침을 검사합니다. lint, typecheck, 단위 테스트 10개, Worker 및 Pages build가 통과했습니다.

실기기 iOS/Android, 전 브라우저 접근성 준수 인증, 저사양 FPS와 실제 NAVER panorama 조회는 이번 테스트 범위가 아닙니다.

## 울산 라인 지도와 조정

간결 모드는 `public/maps/ulsan-lines.geojson`의 OSM 주요 도로·하천·해안선·큰 공원만 표시하는 자체 SVG 스타일입니다. 기존 MapLibre 카메라와 Web Mercator 투영을 공유합니다. 데이터 범위·ODbL·기준일은 `public/maps/README.md`를 따릅니다. 상세는 기존 OSM standard raster이며 범위 밖 또는 라인 파일 실패 시에도 raster fallback을 유지합니다.

조정·기억 목록·폼·인증은 동일한 graphite 표면과 고딕 제목, 산호색 선택 상태를 사용합니다. “모두의 기억 보기 / 내 기억만 보기”는 기존 `/`와 `/my-map`의 인증·조회 계약을 사용하고 연도·감정 필터를 전달합니다. 공개 query에 비공개 데이터를 섞지 않습니다. 저장소 이름과 로컬 저장 key는 데이터 보존을 위해 바꾸지 않습니다.

## Graphite 보완 원칙

사진의 비대칭 배치는 유지하되 사진 없는 큰 감정 표지는 회전하지 않습니다. “의미 있는 순간” 같은 긴 이름도 한 줄로 안정적으로 읽힙니다. 우하단 zoom/current-location 버튼은 모두 44×44px이며 SVG를 같은 중심에 배치합니다.

라인 지도는 실제 OSM의 5개 구/군 면과 경계, 울산 외곽선을 표시합니다. 확대할 때 동·주요 도로명을 순차적으로 드러냅니다. 기억 좌표는 label 배치와 독립적이며 원래 카메라·단일 overlay를 공유합니다. 출처와 한계는 `public/maps/README.md`, 검증 기록은 `YURANG-GRAPHITE-REFINEMENT.md`를 확인합니다.

## 건물과 도시 블록

간결 지도는 선만 남기지 않고 짙은 회청색 도시 블록과 더 밝은 건물 외곽선을 보여 줍니다. 배경은 `#1b2326`을 유지하며 주요 조작의 산호색·본문 흰색보다 낮은 위계를 사용합니다. 신규 표현 토큰은 `--atlas-map-block`, `--atlas-map-industry`, `--atlas-map-building`, `--atlas-map-street`입니다.

건물·도로·블록은 실제 OSM 도형을 사용합니다. 도로로 파생한 블록과 등록된 건물을 서로 구분하며 임의 건물은 생성하지 않습니다. 개요에서는 도시 형태, zoom 13 이상에서는 화면 내 작은 건물까지 나타납니다. 정적 데이터의 출처·누락·정확도 한계는 `public/maps/README.md`를 따릅니다. 기존 기억 마커·투영·권한·지도 fallback은 변경하지 않습니다.

## Cut-paper collage · 팝업과 모달

지도 스탬프와 포스트잇을 서비스 전체의 기준으로 삼습니다. `AtlasHeadingLabel`은 기존 h1/h2/SheetTitle/DialogTitle 안에서만 제목 띠를 표현하며 의미 구조·focus ref·접근성 이름을 대체하지 않습니다.

- 제목: `--atlas-cutout`의 검은 종이 띠와 흰 고딕. 긴 제목은 줄마다 같은 배경을 이어 붙이며 읽는 글을 회전하지 않습니다.
- 본문: 별도의 검은/graphite 종이와 `--atlas-paper-shadow`의 짧은 단단한 그림자. 자유로운 배치는 사진·종이 backing에만 적용합니다.
- 상세: 사진 콜라주와 제목/본문 종이를 분리합니다. 사진 없는 감정은 사용자 선택에 따라 겹친 유기적 원형 윤곽으로 표현합니다. 감정명은 회전하지 않고 수평 한 줄로 읽습니다.
- 장소·공개 탐색: 외부 대형 모달 틀을 줄이고 지도 위 개별 기록 조각으로 보여 줍니다. 장소 목록은 데스크톱의 두 열, 모바일의 한 열을 사용합니다. 마커의 좌표나 작성자의 실제 정보는 장식 배치에 따라 바꾸지 않습니다.
- 조정·작성: 조작이 밀집되므로 안정적인 한 장의 종이로 유지합니다. 공통 제목·44px 닫기 타일·동일한 모서리를 적용합니다. 기존 scroll owner와 고정 action을 보존합니다.
- 인증·튜토리얼·거리뷰: 같은 제목 띠와 종이 경계를 공유하되 인증과 provider callback은 유지합니다.
- 배경은 무거운 blur 대신 낮은 명암의 dim으로 지도를 남깁니다. 색조는 기존 감정 값을 사용하며 밝은 테마로 전환하지 않습니다.

적용·검증 상세는 `YURANG-COLLAGE-REFINEMENT.md`를 확인합니다.

## 소개 문구와 지도 노출

`AtlasIntro`는 메인의 제목·본문 문구만 담당합니다. 본문은 8개 문장 중 mount 시 한 번 고르고 지도 이동으로 재렌더돼도 바꾸지 않습니다. 제목과 본문은 pointer-events를 받지 않아 밑의 지도·마커를 직접 조작할 수 있습니다.

fine pointer의 hover에서는 82px 원형 CSS mask로 문구의 일부만 지워 아래 지도를 드러냅니다. 전체 문구를 숨기거나 지도를 다시 그리지 않습니다. 키보드 사용·영역 이탈 시 mask를 제거합니다. 모바일은 지도에서 6px 이상 이동한 touch gesture 때만 소개의 opacity를 낮추고 마지막 움직임 약 750ms 후 복귀합니다. 탭·폼·패널 스크롤은 이 효과를 시작하지 않습니다. 제스처를 preventDefault/stopPropagation 하지 않으며 MapLibre lifecycle을 바꾸지 않습니다.

텍스트는 DOM에 남아 접근성 구조를 유지하고, reduced-motion에서는 opacity 전환을 끕니다. 구현·검증은 `YURANG-INTRO-REFINEMENT.md`를 확인합니다.
